## 📄 1. ATS Single-Page Resume (`resume.html` & `resume.md`)

### Key Features
- **Strict Single-Page Fit**: Tuned layout, margins, and typography ensuring all sections comfortably fit onto exactly **one page** when printed or saved as PDF.
- **ATS Compliance**: Semantic hierarchy (`<header>`, `<section>`, `<h1>`, `<h2>`, `<ul>`, `<li>`), standard section headings, and machine-readable text without complex multi-column floats or graphic icons that break applicant tracking systems.
- **Keyword Density**: Natural inclusion of high-frequency keywords: `Python`, `REST APIs`, `Algorithms`, `Data Structures`, `Backend Development`, `AI/ML`, `Git`, `GitHub`, `Problem Solving`, etc.
- **Honesty First**: **Zero fabricated claims**, grades, statistics, or unconfirmed technologies. Missing items are clearly formatted as bracketed placeholders.

### 🖨️ How to Export as a 1-Page PDF
1. Double-click [resume.html](resume.html) to open it in Google Chrome, Microsoft Edge, or Firefox.
2. Click the blue **"Print / Save as PDF"** button in the top action bar (or press `Ctrl + P`).
3. In the browser print dialog, configure these settings:
   - **Destination:** *Save as PDF*
   - **Paper size:** *A4* or *Letter*
   - **Margins:** *Default* or *None*
   - **Scale:** *100%* (or adjust to 95% if your browser default adds excess footer padding)
   - **Options:** Uncheck *Headers and footers*
4. Click **Save** to generate your crisp single-page PDF.

## 🌐 2. Modern Interactive Portfolio (`index.html`)

### Key Features
- **Modern Developer Design**: Dark mode by default with electric accents, plus an instant light mode toggle with state saved in `localStorage`.
- **Hero & Profile Showcase**: Includes a developer status pill ("Open for Internships"), animated subtitles, and an interactive **photo upload tester** allowing you to preview how your headshot looks before hosting.
- **Project Showcase**: Highlights *Smart Inventory Management System* and *TradePilot AI* with architecture tags, feature bullets, and repository placeholders.
- **Hackathon Timeline**: Dedicated section highlighting rapid prototyping, API integration, and MVP presentation under pressure.
- **Quick Utilities**: One-click email copy button with toast notification, responsive mobile drawer menu, and direct link to the ATS resume.

### 🚀 How to View Locally
Double-click [index.html](index.html) to open it directly in any web browser. No web server, Node.js, or external installation is required.
